============================================================
PHASE 2 — MULTI-SEED GROKKING EXPERIMENT
============================================================

Phase 1 established a single-seed baseline for:

(a + b) mod p = c

using a tiny Transformer.

Phase 2 asks:

"How consistent is grokking across random initialization seeds when architecture, dataset construction, optimizer, and hyperparameters are held fixed?"

This phase should run multiple independent training experiments and quantitatively compare:

- whether grokking occurs
- when grokking occurs
- memorization time
- delay between memorization and grokking
- final generalization
- variability across seeds

DO NOT implement Fourier/circuit analysis yet.

That belongs to Phase 3.
