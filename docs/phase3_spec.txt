4. IMPORTANT MATHEMATICAL BACKGROUND
============================================================

We are studying:

c = (a + b) mod p

where:

a,b,c ∈ Z_p

and p is typically:

p = 113

For modular arithmetic, construct Fourier basis functions over Z_p.

For frequency k:

cos_k(x) = cos(2πkx/p)

sin_k(x) = sin(2πkx/p)

for:

k = 0,1,...,floor(p/2)

Use normalized Fourier bases when appropriate.

Implement this explicitly with NumPy/PyTorch.

Do not rely on black-box packages for the main analysis.

15. REPRESENTATIONAL SIMILARITY
============================================================

Raw neuron dimensions cannot be directly compared across independently trained models because hidden units can permute or rotate.

Therefore DO NOT compare:

neuron 17(seed A)

directly with:

neuron 17(seed B)

as if neuron identities were aligned.

Use representation-level similarity methods.

Implement at least:

Linear CKA

for residual representations.

Optionally implement:

SVCCA

if computationally practical.

Prefer Linear CKA as the primary metric.

For every pair of seeds compare equivalent layers.

Generate:

and save pairwise similarity matrices.
